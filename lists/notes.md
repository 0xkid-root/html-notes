# HTML Lists

Lists are used to group related items together. There are two main types:

## 1. Unordered Lists (Bullet Points)
Use the `<ul>` tag (Unordered List) for a bulleted list. Each item is an `<li>` (List Item).
```html
<ul>
    <li>Apple</li>
    <li>Banana</li>
    <li>Orange</li>
</ul>
```

## 2. Ordered Lists (Numbered)
Use the `<ol>` tag (Ordered List) for a numbered list.
```html
<ol>
    <li>First step</li>
    <li>Second step</li>
    <li>Third step</li>
</ol>
```
You can change the numbering type with the `type` attribute:
- `<ol type="A">` for A, B, C...
- `<ol type="I">` for Roman numerals (I, II, III...)
